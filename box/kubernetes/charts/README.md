# charts

Standalone [Helm](https://helm.sh) charts distributed as [OCI](https://opencontainers.org) artifacts at `ghcr.io/younsl/charts/{chart}`.

## Background

Helm has supported [OCI registries](https://helm.sh/docs/topics/registries/) as a first-class distribution method since 3.8.0, and it is the recommended way to distribute charts today:

- Container images and charts live in the same registry, sharing one set of infrastructure, authentication, and access control.
- No `index.yaml` to host or regenerate. Publishing a chart is a single push, with no repository server such as ChartMuseum to operate.
- Every version is content-addressable by digest, so a pulled chart can be verified and pinned exactly like a container image.
- Registry-native tooling (crane, cosign, replication, retention policies) works on charts unchanged.

For these reasons this repository publishes charts only as OCI artifacts and does not maintain a classic `helm repo` index.

## Charts

| Chart | Description |
|-------|-------------|
| [argo-workflows-templates](./argo-workflows-templates) | Manages Argo Workflows WorkflowTemplate and ClusterWorkflowTemplate resources. Requires the Argo Workflows controller to be installed first. |
| [grafana-dashboards](./grafana-dashboards) | Deploys Grafana dashboards as ConfigMaps, provisioned automatically by the Grafana sidecar. Supports per-dashboard folder, labels, and annotations. |
| [istio-envoyfilters](./istio-envoyfilters) | Manages Istio EnvoyFilter resources to customize Envoy proxy configurations across namespaces. |
| [karpenter-nodepool](./karpenter-nodepool) | Creates Karpenter NodePool and EC2NodeClass resources. |
| [kubernetes-admission-policies](./kubernetes-admission-policies) | Kubernetes-native admission policies using ValidatingAdmissionPolicy and MutatingAdmissionPolicy with their policy bindings. |

## Install

Charts are OCI-only, so `helm search repo` does not work. Use [crane](https://github.com/google/go-containerregistry/blob/main/cmd/crane/README.md) to discover available versions:

```bash
crane ls ghcr.io/younsl/charts/{chart}
```

Install a chart directly from the registry:

```bash
helm install {release} oci://ghcr.io/younsl/charts/{chart} --version {version}
```

## Release

A chart is released on merge to `main` when `version` in its `Chart.yaml` changes. The release is skipped if that version already exists in the registry.

## Documentation

Per-chart `README.md` files are generated by [helm-docs](https://github.com/norwoodj/helm-docs) from the shared template `README.md.gotmpl`. Never edit them directly. Regenerate with:

```bash
make docs
```

A pre-commit hook runs the same command and fails the commit if the output differs.
